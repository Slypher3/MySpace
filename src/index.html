Password Breach Checker

🔒
How it works: Your password is hashed with SHA-1 locally using crypto.subtle. Only the first 5 characters of the hash are sent to the API. The full hash is compared client-side against returned suffixes. Your password never leaves this device.

About CyberSpace

// Mission

CyberSpace is a client-side network reconnaissance and security awareness dashboard. It uses exclusively free, keyless APIs to provide real-time intelligence about your network exposure, password security, and a dose of programming humor. All processing happens in your browser — no data is sent to any third-party servers beyond the listed APIs.

// APIs Used

  • 🌐
    ipapi.co
    IP geolocation, ISP identification, and ASN lookup. No key required.
    ipapi.co →
  • 🔍
    Shodan InternetDB
    Free endpoint from Shodan exposing open ports, hostnames, tags, and CVEs for any IP.
    internetdb.shodan.io →
  • 🔑
    Have I Been Pwned — Pwned Passwords
    k-Anonymity password breach checker. Only a 5-char hash prefix is sent; full comparison is local.
    haveibeenpwned.com →
  • 😂
    JokeAPI v2
    Programming jokes API. Filtered to the "Programming" category for maximum nerd cred.
    v2.jokeapi.dev →
  • 🕵️
    Gravatar
    Public avatar and profile lookup via MD5 email hash. No key required.
    gravatar.com →
  • 🚨
    XposedOrNot
    Email breach database. Returns detailed breach history, exposed data types, password risk, and breach timeline. Free, no key.
    xposedornot.com →
  • 🌐
    Cloudflare DNS-over-HTTPS
    Public DNS resolver for MX, SPF, and DMARC record lookups. Used for email domain security auditing.
    cloudflare-dns.com →

// Tech Stack

Pure HTML / CSS / JavaScript. No frameworks, no build tools, no dependencies. Just raw code in the void.

🕵️

Email Reconnaissance

Enter an email address to scan its Gravatar profile, verify mail server existence, and audit anti-spoofing protections (SPF, DMARC). All lookups use public DNS records and the Gravatar API.

🔒
Privacy: Email is hashed locally with MD5 for Gravatar. DNS lookups query public records via Cloudflare DoH. No data is stored or sent to third-party servers beyond these APIs.
